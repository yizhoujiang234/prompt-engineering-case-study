# 提示词优化器 · Prompt Optimizer

一个纯前端的提示词优化工具：**简单写下你要干嘛，得到一份结构化、可直接使用的提示词**。
方法论来自同级目录的 [Claude-Fable-提示词工程项目](../Claude-Fable-提示词工程项目/)——
对一份 2195 行生产级系统提示词的拆解（五层架构 / 10 个设计模式 / 评审清单）。

## 快速开始

双击 `index.html` 即可（Vue 3 运行时已本地化，无任何构建步骤、无外部请求）。
也可以用任意静态服务器：`python -m http.server 8080`。

## 功能

```
输入粗略想法 → 选择类型与选项 → 生成 → 渲染/源码双视图 → 一键复制
```

- **两种提示词类型**：任务提示词（让模型干一件事）/ 系统提示词（搭建一个助手）
- **六个开关**：输出格式规范、边界与追问、判断测试、示例占位、自检清单、数值硬限
- **三个结果视图**：优化后的提示词（Markdown 渲染）/ 评审检查（10 项启发式自动检查）/ 用了哪些方法（溯源到设计模式）
- **两种生成方式**：
  - **本地结构化优化**——浏览器内完成，不联网、无需配置；
  - **AI 深度优化**——把完整方法论注入系统提示词，调用大模型真正改写。

## AI 模式配置

点「⚙ AI 设置」，选择服务商后 Base URL 自动填好，填入 API Key 和模型名即可：

| 服务商 | 默认模型（2026-09 核实） |
|---|---|
| DeepSeek（默认） | `deepseek-v4-flash` |
| Kimi（月之暗面） | `kimi-k3` |
| 通义千问 | `qwen3.8-flash` |
| OpenAI | `gpt-5.6-sol` |
| Anthropic（Claude） | `claude-sonnet-4-6` |
| 自定义 | 任意 OpenAI 兼容端点（含 Ollama / LM Studio 本地模型） |

配置（含 Key）只保存在**本机浏览器 localStorage**，请求从你的浏览器直接发往服务商，
不经过任何中间服务器。

## 隐私

- 本地模式：一切计算在浏览器内，零上传；
- AI 模式：你输入的内容会发给你自己配置的模型服务商（受其隐私政策约束）；
- 页面无任何统计/追踪脚本。
