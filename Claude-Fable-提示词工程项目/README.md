# Claude Fable 5.1 · 提示词工程项目

> 源文档：一份 2195 行 / 约 275 KB（估算 6.5–7 万 tokens）的**生产级消费类 AI 助手系统提示词**。
> 本项目将其拆解为 **19 个可独立维护的模块**，配套架构分析、设计模式提炼、
> 可复用模板与重组验证脚本——把"一份 2000+ 行的提示词"变成"一个可维护的工程项目"。

## 快速开始

```powershell
# 1. 重新切分（以 original/ 为基准）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\split.ps1

# 2. 重组并校验
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\rebuild.ps1
# 输出 PASS = modules/ 可无损还原原文
```

## 核心发现（TL;DR）

1. **记忆系统独占 38.2%**——这份提示词的重心不是"聊天"而是"跨会话个性化"，
   含完整的三层隐私禁存模型与行为护栏（拒绝"只夸不批""培养依赖"类指令）；
2. **规则几乎都配正反示例**：记忆应用 17 例（6 组）、版权 3 例（带 rationale）、
   搜索 5 例——示例即规范；
3. **用"判断测试"代替死规则**："一个月后还成立吗"（该不该记）、
   "同事看到会不会不适"（该不该存）、"引用 <15 词"（版权红线）；
4. **能力靠路由组织**：连接器先 suggest 后 call、图表四步检查表
   （MCP → 专业工具 → Visualizer → 文字）、文件"独立产物 vs 内联回答"判定；
5. **46 个工具的 description 本身就是提示词工程**——触发词、排除项、
   优先级全写在工具描述里，正文只管高层路由。
