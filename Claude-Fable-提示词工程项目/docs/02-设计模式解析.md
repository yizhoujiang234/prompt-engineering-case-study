# 设计模式解析：10 个可复用的提示词工程套路

> 每个模式给出：定义 → 原文证据（行号）→ 生效机制 → 复用要点。
> 行号均指 `original/Claude-Fable-5.1.md`。

## 模式 1：关键块定级（Criticality Wrapping）

**定义**：把不可妥协的规则用特殊标签/全大写包裹，与普通规则视觉区分。

**原文证据**：
- `<critical_child_safety_instructions>`（L28–39）
- `<CRITICAL_COPYRIGHT_COMPLIANCE>`（L1497–1593）
- `<critical_reminders>`（L1660–1677）

**生效机制**：标签名 + 大写形成双重信号，提高模型服从性；同时便于人类维护时
快速定位"绝对不能碰"的规则。

**复用要点**：安全底线 3–5 条放 critical 块，其余平铺。**不要滥用**——
全文都是 critical 等于没有 critical。

## 模式 2：正反例三件套（good / bad / rationale）

**定义**：每条易出错的行为规则配一组"好回答 + 坏回答 + 理由"。

**原文证据**：
- 记忆应用示例：17 个 `<example>`、6 个 `<example_group>`（L885–1007），
  后半部分每组都同时给 `good_response` 与 `bad_response`；
- 版权示例 3 组，每例带 `<rationale>`（L1552–1581）；
- 搜索触发示例 5 组（L1596–1648）。

**生效机制**：反例划出失败模式的边界（比正面描述更精准）；
rationale 让规则可解释，减少模型过度泛化或过度保守。

**复用要点**：规则 + 1 组正反例 + 一句话 rationale，是性价比最高的提示词单元。

## 模式 3：判断测试替代枚举（Heuristic Tests）

**定义**：当枚举列不全时，改用一个可操作的问句让模型自行判断。

**原文证据**：
- 记忆写入的"地平线测试"——这条信息一个月后还成立/还有用吗？（模块 06）
- 隐私"同事测试"——如果同事看到这条记忆会不适吗？（L701–766 遗漏指引段）
- 版权"15 词线"——直接引用少于 15 词（L1506–1539）

**生效机制**：枚举永远有遗漏，问句可以泛化到未见场景；同时问句天然比规则更"轻"，
不占语义注意力。

**复用要点**：当你的 if-else 规则列表超过 5 条，停下来改写成一个问句测试。

## 模式 4：数值硬限（Numeric Hard Limits）

**定义**：把"适度/尽量/一般"换成可数、可审计的数字。

**原文证据**：

| 数字 | 规则 | 位置 |
|---|---|---|
| <15 词 | 单次直接引用上限 | L1506–1539 |
| ≤1 次 | 每来源直接引用次数 | 同上 |
| 3–4 张 | 图片搜索每次数量，且连续调用 | L1711–1720 |
| 1 张 | 每会话插件推荐卡片上限 | L1176–1193 |
| 1000 | Artifact 内 API max_tokens 固定值 | L1839–1840 |
| 1929 | 公版作品年份线（之前可复现） | 模块 02 |

**生效机制**：模型输出前可自检（数一数），人工可审计（查一查）。

**复用要点**：写完规则后扫一遍"适度、尽量、一般来说、少量"——每个都要换成数字。

## 模式 5：路由决策树（Explicit Routing）

**定义**：多工具/多出口场景写成显式的有序决策步骤 + 默认出口。

**原文证据**：
- MCP 连接器：必须先 `suggest` 后 `call`，电商场景永不主动推荐（L1127–1174）；
- 图表路由四步检查表：MCP → 专业工具 → 内置 Visualizer → 纯文字（模块 11，L1368–1439）；
- 文件产出判定："独立产物 vs 对话内回答"（博客/文章 → 文件；策略/摘要 → 内联）（L1279–1348）；
- 必须搜索的三类：现任职位、快变信息、未识别实体（L1473–1495）。

**生效机制**：把"选择困难"变成按序问答，压缩模型自由发挥空间；
默认出口保证决策树永远走得出。

**复用要点**：任何 ≥2 个工具竞争的场景都写决策顺序；最后一步永远是"兜底"。

## 模式 6：三层隐私模型 + 行为护栏

**定义**：隐私规则分级管理，并对"合法但有害"的用户指令设护栏。

**原文证据**（L663–803）：
- `protected_attributes`（L670–672）：种族、宗教等 → **默认不存**；
- `sensitive_information`（L674–678）：政治、财务、健康 → **谨慎存**；
- `never_store`（L680–699）：证件号、未成年身份、移民状态、犯罪史 → **绝不存**；
- `behavioral_guardrails`（L768–802）：即使**用户明确要求**，也不执行
  "只夸不批""培养情感依赖"类记忆指令。

**生效机制**：分级比一刀切可执行；行为护栏防的是提示词注入的"合法变体"
（用户自愿授权存有害偏好）。

**复用要点**：任何带记忆/存储功能的产品，隐私至少分三级，
并补一条"明确要求也不存"的行为护栏。

## 模式 7：禁用表述清单（Banned Phrases）

**定义**：直接封杀特定话术，比"要自然"之类的抽象要求可执行得多。

**原文证据**：
- 避免 "genuinely / honestly" 等填充词（L83–97 语气段）；
- 禁说 "Based on your memories…" 类开场（L859–877）；
- 不使用诊断语言；不建议冰块/橡皮筋"替代法"（L119–151）。

**生效机制**：模型高频翻车的措辞是可统计的，逐条封杀见效最快。

**复用要点**：上线后收集坏回答的措辞特征，维护一张"禁用 → 替换"表，持续追加。

## 模式 8：示例组工程化（Example Groups by Behavior）

**定义**：示例不是散放的，按行为维度分组，组名本身就是分类学。

**原文证据**（L885–1007，记忆应用示例的 6 个分组）：
1. Simple Greetings（最小场景）
2. Direct Factual Questions（直答场景）
3. Natural Integration of Context（自然融入场景）
4. Calibrating Technical Depth（深度校准场景）
5. **When NOT to Apply Memory**（不用场景）
6. **Boundaries**（边界场景：拒绝情感依赖）

**生效机制**："何时不用"与"边界"两组反直觉地重要——它们防止能力被滥用；
分组标题教会模型先分类再行动。

**复用要点**：示例覆盖至少 4 类：最小、典型、**不用**、**边界**。

## 模式 9：运行时占位与注入（Runtime Placeholders）

**定义**：易变内容不写死在提示词里，做成占位符由系统每会话拼装。

**原文证据**：
- `<profile>(not yet written)</profile>`、`<memory_listing>`（L1817–1823）；
- 当前日期声明为"在下方对话中提供"（L1812）；
- 用户位置 `{LOCATION_REDACTED}`（L2043）。

**生效机制**：静态部分可版本化审阅，动态部分由数据管线保证新鲜；
两者解耦后，提示词迭代不碰用户数据。

**复用要点**：日期、用户档案、清单、环境配置一律占位符化；
手工只维护静态层。

## 模式 10：工具描述即提示词（Tool Descriptions as Prompting）

**定义**：把路由规则下沉到工具的 `description` 字段，正文保持简洁。

**原文证据**（L1762–1807，46 个工具）：
- xlsx：触发词 "any time a spreadsheet file is the primary input or output"
  + 一长串"不要用于"排除项；
- product-self-knowledge（技能）："你的训练数据可能过时或错误，请来这里核实"；
- 图片搜索工具："Default to using image search…"（默认行为直接写进描述）。

**生效机制**：模型选工具时主要读 description；描述里写"何时用/何时不用/
与相近工具的优先级"，比在正文写长篇路由规则更贴近决策点。

**复用要点**：新工具 description 三要素——**何时用、何时不用、和谁比优先级**。
